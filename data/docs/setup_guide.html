Laptop setup guide

دليل تجهيز الجهاز

AI & Data Readiness Program · Day 1 lab — please do this before Day 1. It takes about 30 minutes.

برنامج جاهزية الذكاء الاصطناعي والبيانات · معمل اليوم الأول — نرجو إتمام هذه الخطوات قبل اليوم الأول، وتستغرق نحو ٣٠ دقيقة.

You need: 8 GB RAM (16 GB better), 20 GB free disk, admin rights, internet. Everything is free.

المطلوب: ذاكرة ٨ جيجابايت (والأفضل ١٦)، ومساحة فارغة ٢٠ جيجابايت، وصلاحيات المسؤول على الجهاز، واتصال بالإنترنت. كل الأدوات مجانية.
# Step الخطوة
1 Install Python 3.11 or newer from python.org. On Windows, tick Add python.exe to PATH.
ثبّت Python 3.11 أو أحدث من python.org. في Windows اختر Add python.exe to PATH.
2 Install VS Code and its Python and Jupyter extensions.
ثبّت VS Code ثم إضافتي Python وJupyter.
3 Install Git from git-scm.com.
ثبّت Git من git-scm.com.
4 Get the data kit: git clone [KIT_REPO_URL — to be confirmed] into a folder without spaces or Arabic letters in its path, e.g. C:\work\oasis_datakit.
انسخ حقيبة البيانات بالأمر git clone في مجلد مساره بلا مسافات أو حروف عربية، مثل C:\work\oasis_datakit.
5 In a terminal inside the folder: python -m venv .venv, activate it (.venv\Scripts\activate on Windows, source .venv/bin/activate on macOS/Linux), then pip install -r requirements.txt.
من الطرفية داخل المجلد: أنشئ بيئة افتراضية وفعّلها، ثم ثبّت المكتبات بالأمر pip install -r requirements.txt.
6 Open the folder in VS Code, open labs/D01/hello_oasis.ipynb, choose the .venv kernel and Run All. You should see the six zones and Total residents: 60000.
افتح المجلد في VS Code، ثم الدفتر labs/D01/hello_oasis.ipynb، واختر النواة .venv واضغط Run All. يجب أن تظهر المناطق الست و«إجمالي السكان ٦٠٠٠٠».
7 Take a screenshot of the result — you will submit it on Day 1.
التقط صورة للشاشة للنتيجة، فستسلّمها في اليوم الأول.

Plan B — Google Colab. If anything fails, go to colab.research.google.com, sign in, File → Upload notebook → hello_oasis.ipynb, and Runtime → Run all. The first cell downloads the kit for you.

الخطة البديلة: Google Colab. إذا تعثّر أي شيء، افتح colab.research.google.com وسجّل الدخول، ثم ارفع الدفتر hello_oasis.ipynb وشغّل كل الخلايا. الخلية الأولى تُنزّل الحقيبة تلقائيًا.

Common problems

مشكلات شائعة
Problem Fix الحل
python not found Reinstall with Add to PATH; open a new terminal.
أعد تثبيت Python مع خيار PATH، ثم افتح طرفية جديدة.
Arabic shows as boxes Open the file in VS Code or Jupyter, not Excel. CSV files are UTF-8.
افتح الملف في VS Code أو Jupyter وليس Excel، فالملفات بترميز UTF-8.
git clone blocked Download the ZIP from the same page.
نزّل الملف المضغوط ZIP من الصفحة نفسها.

All data in the kit is synthetic, for training only.

كل البيانات في الحقيبة اصطناعية لأغراض التدريب فقط.
